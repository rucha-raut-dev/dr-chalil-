# Dr. Joseph M. Chalil — Premium Portfolio

A completely new single-page portfolio experience built with Next.js, React, TypeScript and Tailwind CSS.

## Design direction
- Editorial / executive art direction rather than a template-like card grid
- Balanced typography, image scale and whitespace
- Ivory, ink and muted sage palette
- Subtle borders and motion; no gradients or oversized UI
- Responsive navigation and layouts
- Real public biography, career, education, books, publications, patents, awards, media and gallery content
- Internal section navigation; the new experience does not route users back into the legacy site

## Run
```bash
npm install
npm run dev
```
